# animations-bundle-dancing

Пакет танцевальных анимаций для Morphia-совместимых персонажей. Это отдельная
зависимость, не движок и не плеер анимаций.

## Состав

Каждый танец хранится в собственной папке: `animations/give-your-soul/`,
`animations/planet-b/` и `animations/planet-b-challenge/`. В каждой лежат
`manifest.js` и три полных файла `.mda`: `capsule.mda`, `vrm.mda`,
`animebase.mda`, а также оригинальный FBX в этой же папке. FBX содержит
капсульного персонажа со скелетом из 85 костей и исходными анимационными
дорожками; он пригоден как исходник для повторной обработки или других
совместимых инструментов. MDA — версии движения для соответствующих ригов
Morphia: 22 основные кости и перемещение таза, 60 кадров/с; они не содержат
мешей, текстур или звука. Runtime Morphia загружает MDA, а не FBX.

```js
import { DANCE_MANIFESTS } from 'animations-bundle-dancing';
// manifest.files.capsule, .vrm, .animebase и manifest.sourceFbx — пути
// относительно корня пакета.
```

Файлы не загружаются автоматически: приложение должно раздавать каталог
`animations` как статические файлы либо включить его в собственную сборку и
преобразовать относительные `files` в URL своего сервера. `MDA1` — формат Morphia,
для воспроизведения необходим совместимый плеер. Пакет не привязан к Vite,
конкретному хосту или глобальному URL. Проверка целостности в исходном репозитории: `npm test`.
